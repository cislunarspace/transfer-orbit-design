# 代码说明

当前代码可生成 CRTBP（圆型限制性三体问题）模型下的 DRO、Halo 等周期轨道。

# 下一步工作

需要理解各函数的功能，并对各个文件中的函数进行系统整理。

在本代码仓库中，我期望逐步添加新的函数和功能。首先是对代码结构进行良好组织，主要包括以下内容：

1. **动力学外推函数**  
   提供统一接口，通过 switch 机制选择不同的动力学模型。

2. **坐标转换矩阵**  
   实现一系列以名称标识的坐标系间转换函数。

3. **参数管理**  
   由一个统一的文件集中存储所有基本参数。

为实现上述目标，采用如下目录结构：

- `CoordinateTrans/`：存放坐标转换矩阵相关函数  
- `Dynamics/`：存放动力学外推函数  
- `Parameters/`：存放系统参数定义  
- `Funcs/`：存放辅助功能函数  
- `Main/`：存放主函数与高层算法  
- `envi/`：存放 Python 虚拟环境  
- `Spice/`：存放星历文件
