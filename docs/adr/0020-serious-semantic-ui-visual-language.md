# 0020. UI 视觉语言定为严肃语义色板

- 日期: 2025-02-25
- 状态: 提议 (Accepted)

界面自 PyQt 重构为 Tauri + Ant Design 6（ADR-0014/0015）后，沿用了 antd 默认的圆润亮色风格（8px 圆角、活泼的 `#1890ff` 主色）。为匹配轨道设计工具的严肃技术气质，我们有意偏离 antd 默认视觉：

- **直角**：全局 `borderRadius` 全系列（base/LG/SM/XS/Outer）统一降到 **2px**。
- **收敛语义色板**：整个界面只用黑/白/灰/红/蓝/绿/橙七种色相——红=错误、绿=成功、橙=警告、蓝=主色/信息，中性色沿用 antd 灰阶。主色蓝从 `#1890ff` 收敛为深蓝 `#0958d9`。
- 直接写死为主题 token 的新默认，不设用户配置项。

这是一处对 antd 默认风格的有意偏离。后续开发者看到直角与收敛主色时，不应将其"修复"回 antd 圆润默认——那不是 bug，是设计方向。
