# ADR 0014：主画布时间轴（时刻选择）

**状态**：已接受
**日期**：2026-08-12
**关联**：ADR 0013（星历模型可视化的坐标与时间约定，决策 6 被本 ADR 修订）

## 背景

用户需要拨动时间观察飞行器在轨道上的真实位置，且地球、月球使用真实位置。经原型（`src/view/prototype_timeline.py`，一次性分支留档）验证三个会合系行为变体后确定方案：会合系保持静态 CR3BP 几何（文献主流），真实公转平面由惯性系视图承担（ADR 0013 既有决策不变）。

## 决策

1. **形态**：画布下方新增 Qt 滑块（scrubber），选择物理时刻 t（et 秒），旁显 UTC。不做播放按钮。
2. **作用对象**：仅带 `times_et` 的星历产物（design_orbit 标称星历、control_orbit 受控星历），飞行器 marker 在轨迹上走到 t 对应位置。初猜（CR3BP，无物理时间）不受时间轴影响；同屏无星历产物时时间轴灰显。
3. **两系行为**：惯性系下飞行器点在 `position_km` 轨迹上移动，另加月球此刻位置 marker 随 t 移动（月球轨迹仍整条显示，地球原点不动）；会合系下轨迹静态，仅飞行器点沿线移动，地月/平动点标注不变。两系共享同一 t，切系不重置滑块。
4. **滑块区间**：所有可见星历产物 `times_et` 的并集；超出某产物范围的时刻该产物的飞行器点消失。
5. **渲染**：拖动走全量重绘 `render()` + 节流（拖动中约 10 Hz），不建增量渲染路径。

本 ADR 修订 ADR 0013 决策 6 中主画布不做实时播放/时刻交互的部分；GIF 导出工具不变。

## 理由

- 会合系静态几何是脉动-旋转系的定义（ADR 0013 文献调研，Folta 2022 等），原型中的轨迹随月相旋转变体被否决，真实几何看惯性系即可，会合系看周期结构。
- 初猜无真实历元，用周期映射造相位会画出物理上不存在的东西。
- 全量重绘复用现有 `render()` 单入口；仅一个 marker 移动，节流后体验够用，增量路径的残留元素类 bug 风险不值得。

## 后果

- `CanvasState` 需新增时刻字段，参与重绘判定；时间轴是画布状态而非某个视图的私产。
- 惯性系时间轴依赖 SPICE 内核（查月球此刻位置），离线环境降级为无月球 marker。
