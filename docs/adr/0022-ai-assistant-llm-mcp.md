# ADR 0022：AI 助手（LLM+MCP）功能定位与模型服务策略

**状态**：已接受
**日期**：2026-08-29
**关联**：ADR 0003（运行前预确认，本 ADR 把确认语义扩展到 AI 发起的工具调用）；ADR 0023（AI 助手的架构实现）；e2m2e ADR 0014（Facade/MCP/CLI 接口层）

## 背景

e2m2e 自 5.8.3 起以 `mcp-serve` 子命令提供标准 MCP 服务（stdio 传输，`tools/list` + `tools/call`，仅注册 implemented 状态的工具），本仓依赖 `e2m2e>=5.8.5` 已包含该能力；工具的 input schema 与前端 `toolSchemas/*.json` 同源（同一 Pydantic 模型导出）。GUI 规划提供内嵌 **AI 助手**：用户在右侧 **助手边栏** 以自然语言描述轨道设计目标，助手经 LLM+MCP 闭环调用 e2m2e 工具并解读结果。

本功能的长期方向是用户论文草稿《基于大语言模型的地月空间飞行器轨道追逃博弈策略设计研究》（2026-08，解程旭、欧阳嘉鸿、朱彦伟等）提出的"模式三"框架——"语言规划器＋数值执行器＋安全验证器"受控流水线（态势文本化—提示工程—策略解析执行—策略评估）。

## 决策

1. **能力范围**：助手以"工具调用 agent＋结果解读"为核心——理解自然语言意图、组装工具参数、经确认后运行 MCP 工具、用自然语言解读结果与诊断信息。领域知识问答随系统提示顺带获得，不单独投入。
2. **分阶段对齐模式三**：边栏先做通用助手跑通 LLM+MCP 基础设施；架构决策向模式三对齐（系统/任务/态势三层提示、结构化工具调用协议、可插拔验证链挂点），追逃博弈场景流水线（可达域分析、相对状态、捕获判据等执行器）随 e2m2e 上游工具落地后建。追逃术语（追击者/逃逸者/捕获判据/态势）届时再进 CONTEXT.md。
3. **人在回路**：助手仅响应用户消息，不主动发起行为、不后台自发行动；可在回复文本末尾建议下一步。
4. **分级确认**：**只读工具**（不运行数值计算、不改变状态、只返回已有数据）助手可免确认直接调用；其余工具的调用须向用户展示工具名与参数摘要，经确认后运行，用户可修改参数后再确认。ADR 0003 的预确认语义由此扩展到 AI 发起的调用。
5. **模型服务策略**：BYOK——用户自备 API key，在设置面板的 AI 助手分区配置 provider 类型、base URL、模型名与密钥；首期支持 OpenAI 兼容协议（覆盖 DeepSeek/通义/Kimi 等国内可达服务，以及 Ollama/LM Studio 本地端点），Anthropic 原生协议后续；LLM client 抽象为可替换接口，对底层模型中性。
6. **数据边界**：本项目数据（CR3BP 轨道设计参数与产物）经用户确认无保密要求（2026-08-29），云端 BYOK 可接受；有保密需求的用户经同一 OpenAI 兼容端点接入本地模型即可，无需额外开发。
7. **语言**：助手回复语言跟随 **界面语言**（ADR 0001）；边栏全部用户可见文本走 i18n 中英双语。
8. **结构化工作流**：助手遵循"先探索、再规划、后执行"——面对多步任务先输出显式计划（步骤＋将调用的工具）再逐步执行；承诺计算前先用只读工具侦察（决策 4 的只读免确认使探索零摩擦）；工具清单覆盖不了用户需求时如实说明缺项，不编造能力；工具的语义化错误（参数校验失败、OrbitError 等）原文回灌给模型自纠，自纠次数设上限。依据：AstroReason-Bench（Wang et al. 2026）实证裸 ReAct 循环存在动作偏置（不查地面轨迹就注册观测条带）、Plan 模式显著改善规划质量；李胤慷等（2026）步骤 1 的工具集缺项检测。

## 理由

- 追逃场景所需的执行器（可达域分析、相对状态、捕获判据）在 e2m2e 现有 MCP 工具清单中不存在，模式三完整落地现在缺数值执行器；先把基础设施跑通、同时不给模式三关门，是分阶段的现实依据。
- 论文指出模式二自由循环"工具可用≠工具被正确使用"、慢且贵、行为不可复现——但通用助手形态对"轨道设计助手"这一当下目标仍是最灵活的载体；三层提示与验证链挂点使未来切换到受控流水线时无需重构 agent loop。
- BYOK＋OpenAI 兼容协议用一个实现覆盖多数国内提供商与本地端点；用户自选提供商即自行承担数据出域决策（论文模式三的"模型中性"与"涉密适应性"诉求由此满足）。
- 论文原件存于微信临时目录，易失且为未发表草稿，不入本公开仓库；其框架内容已由本 ADR 与 CONTEXT.md 吸收。
