# ADR 0028：会合视图改用地心归一显示约定

**状态**：已接受
**日期**：2026-09-02
**关联**：ADR 0013（星历可视化坐标与时间约定，其决策 1 曾定会合系质心归一）；CONTEXT.md（坐标系：数据系 vs 视图系）

## 背景

ADR 0013 决策 1 把会合视图统一定为**质心归一**（Earth@−μ，Moon@1−μ，原点在地月质心）。用户在使用中反馈「画布上地球不在坐标系原点」——这不是渲染错位，而是原点约定使然：质心归一遵循 CR3BP 教科书口径，地球天然在 −μ（≈0.012 DU）。

同时，分区图层（`regionLayer`）的圆心吸附已经把地球吸附到 `(0,0,0)`、月球吸附到 `(1−μ,0,0)`，与画布天体的 `(−μ,0)`/`(1−μ,0)` 在地球一处已不一致（差 μ）。统一到地心归一后此不一致自然消除。

期望口径：**会合视图下地球居坐标系原点**（地心归一显示约定）。

## 决策

1. **显示约定**：会合视图改用**地心归一**渲染——地球在 `(0,0,0)`、月球在 `(1,0,0)`。这是**视图系（显示层）的 +μ 平移**，不改变任何数据数值或数据系标签：`synodic_nd`/`synodic_km` 仍按质心归一的 e2m2e/CR3BP 口径产出，画布在消费时整体 +μ 平移后绘制。
2. **平移范围**：天体（地/月）、平动点 L1–L5、全部会合系轨迹（含时刻标记）、分区图层月球吸附位置，统一 +μ；坐标轴与网格刻度不改动（0 即地心、1 即月心，本就是整数刻度）。
3. **居中偏移重算**（会合视图）：`earth→0`、`moon→−1`、`barycenter→−μ`（质心在地心归一下位于 +μ）、`l1/l2→−(x+μ)`。
4. **惯性视图不变**：地球本就在原点，月球沿 GCRS 真实轨迹，不消费此平移。

## 理由

- 满足「地球居原点」的显示期望，且与分区图层既有的地心吸附口径对齐，消除一处 μ 不一致。
- 只动显示层：数据契约、算法层（`facade_bridge.centroid_normalized_states` 的 −μ、`gcrs_to_synodic`、前端 CR3BP 传播）全部不变，改动最小、可逆。
- 质心归一仍是 CR3BP 教科书与 e2m2e 上游的数据口径，显示层的地心化只是视图选择，与 ADR 0013 的「数据系 vs 视图系」边界一致。

## 后果

### 正面

- 会合视图下地球落在坐标轴原点，L1–L5、网格刻度与轨迹全部同口径 +μ 自洽。
- 消除分区图层月球/地球吸附与画布天体之间的 μ 级错位。

### 负面

- 会合视图显示口径与 CR3BP 教科书质心原点约定分叉：屏幕上 x=0 是地心而非质心，质心落在 x=+μ（近乎不可见的 0.012 DU 偏移）。
- 居中选项「质心」在地心归一下对应 −μ 偏移，与旧实现「质心居中即零偏移」语义略有变化（仍正确：质心确实在 +μ）。

## 后续

- **AI 产物口径**：助手提示词（`src-tauri/src/assistant/prompt.rs`）对会合系坐标的描述尚未提及地心显示平移；如助手需要向用户复述画布坐标，应注明「画布会合系以地心为原点（数据 synodic_nd 为质心归一，+μ 平移后显示）」。
- **默认居中**：若用户希望默认视角直接居中地球（而非质心），把 `App.tsx` 的 `center` 初值从 `barycenter` 改为 `earth` 即可，本 ADR 不默认改（保持「质心居中」为既有默认）。
- **数据口径对齐（可选）**：若将来想把 `synodic_nd` 的数据口径本身也迁到地心归一（去掉 `centroid_normalized_states` 的 −μ 与画布 +μ 的往返），需同步改算法层与 CR3BP 传播，属更大变更，不在本 ADR 范围。
