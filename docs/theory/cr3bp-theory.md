# CR3BP 理论

## 圆型限制性三体问题

CR3BP 描述了一个可忽略质量的天体在两个大质量天体（主天体和次天体）围绕共同质心做圆轨道运动时的引力作用下的运动。

### 坐标系

采用**旋转 Poincaré 坐标系**：
- 原点位于两个主天体的质心
- x 轴从主天体（地球）指向次天体（月球），即地球位于 (-μ, 0)、月球位于 (1-μ, 0)
- y 轴位于轨道平面内
- z 轴完成右手坐标系
- 坐标系以角速度 ω = 1（无量纲）旋转

```
                    ^ y
                    |
            P1      |      P2 (月球)
         (地球)      |        •
            •       |        
                    |
                    +------> x
                   /       
                  /        
                 /         
                v z (垂直纸面)
```

### 运动方程

在无量纲单位下，运动方程为：

$$\ddot{x} - 2\dot{y} = x - \frac{(1-\mu)(x+\mu)}{r_1^3} - \frac{\mu(x-1+\mu)}{r_2^3}$$

$$\ddot{y} + 2\dot{x} = y - \frac{(1-\mu)y}{r_1^3} - \frac{\mu y}{r_2^3}$$

$$\ddot{z} = -\frac{(1-\mu)z}{r_1^3} - \frac{\mu z}{r_2^3}$$

其中：
- $r_1 = \sqrt{(x+\mu)^2 + y^2 + z^2}$ — 到主天体的距离
- $r_2 = \sqrt{(x-1+\mu)^2 + y^2 + z^2}$ — 到次天体的距离
- $\mu = m_2 / (m_1 + m_2)$ — 质量比

### Jacobi 常数

Jacobi 积分提供一个守恒量：

$$C_J = 2\Omega(x,y,z) - (v_x^2 + v_y^2 + v_z^2)$$

其中引力势为：

$$\Omega(x,y,z) = \frac{1-\mu}{r_1} + \frac{\mu}{r_2} + \frac{1}{2}(x^2 + y^2)$$

### Lagrange 点

五个平衡点（Lagrange 点）满足 $\ddot{r} = 0$：

| 点 | 位置 | 稳定性 |
|----|------|--------|
| L1 | 地球和月球之间 | 不稳定 |
| L2 | 月球外侧 | 不稳定 |
| L3 | 地球对面侧 | 不稳定 |
| L4 | 月球前方 60° | 稳定 |
| L5 | 月球后方 60° | 稳定 |

### 状态转移矩阵

对于变分方程，6×6 状态转移矩阵（STM）传播如下：

$$\dot{\Phi}(t) = A(t)\Phi(t), \quad \Phi(t_0) = I_{6\times6}$$

其中 $A(t)$ 是运动方程的 Jacobian 矩阵。
