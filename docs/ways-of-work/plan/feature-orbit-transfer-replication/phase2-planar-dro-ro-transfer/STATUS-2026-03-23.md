## 4. NLP 优化问题分析

### 4.1 问题定义

**优化变量**: `y = {α, T, t_ins}`

**目标函数**: 
```
J(y) = Δv₁ + Δv₂
```

**约束条件**:
1. **位置连续性约束** (等式): `(x_f - x_ins)² + (y_f - y_ins)² + (z_f - z_ins)² = 0`
2. **速度平行性约束** (等式): `v_f · v_ins / (||v_f|| ||v_ins||) - 1 = 0`
3. **不撞击约束**: 距离地球 > 0.02 DU，距离月球 > 0.005 DU

### 4.2 scipy.optimize (SLSQP) 测试结果

| 测试场景 | 结果 | 说明 |
|----------|------|------|
| 仅边界约束 | ✅ 成功 | 17次迭代，ΔV ≈ 0.055 |
| 位置+速度等式约束 | ❌ 超时 | 约束过严，难以同时满足 |
| 松弛速度约束 (5°) | ⚠️ 未测试 | 需要调试 |

**初始猜测测试**:
```
初始: α=1.0, T=10.0, t_ins=5.0
目标函数值: 1.4859
位置约束违反: 0.9999
速度约束违反: -1.2139
```

### 4.3 问题根因

1. **等式约束过严**: 位置连续和速度平行需要同时满足，DRO和RO轨道差异大
2. **初始猜测不佳**: (1.0, 10.0, 5.0) 不在可行域内
3. **SLSQP 对等式约束敏感**: 数值稳定性问题

### 4.4 约束违反情况分析

从网格搜索结果看:
- 最佳解 min_distance ≈ 0.0008 (近似相交)
- 但速度平行性未验证
