# 界面总览

## 三栏布局

主窗口按左、中、右三栏排布，分隔条可拖拽调整比例：

| 栏 | 内容 | 作用 |
|----|------|------|
| 左侧 | 项目树 | 按类型分组展示全部计算产物，支持点击/多选/右键操作 |
| 中间 | 可视化画布 + 日志标签页 | 画布展示轨道，日志逐条输出运行进度 |
| 右侧 | 工具选择器 + 工具说明 + 参数面板 + 运行/重置按钮 | 发起计算 |

右侧参数面板按组展示（轨道设计：形状/传播/修正参数；轨道保持：控制/仿真与
误差/角动量管理），每个可换算数值参数带单位下拉框（国际单位与归一化
DU/TU 切换），数值框清空时显示"可填范围"占位提示；"重置参数"按钮恢复
默认值。工具下拉与 e2m2e facade 工具清单对齐，未接入的工具灰显"即将提供"
（悬停显示工具说明），详见 {doc}`tools`。

顶部菜单"设置 → 图表设置…"可调整画布线宽、颜色方案、标注大小、字号与
Z 区间比例（见 {doc}`visualization`）。

## 工件（Artifact）与项目树

**工件**是 GUI 管理计算产物的基本单位——一次工具运行产生一个工件。启动时
程序扫描 `output/` 目录，把历史结果重建为工件；运行新工具后新工件立即出现
在树中。

项目树按工件类型分组：

```
📁 项目: Transfer Orbit Design
├─ 🪐 轨道
│  ├─ DRO (20260813...)        ← 点击 → 渲染到画布
│  └─ Halo (20260813...)
├─ 🌀 轨道族
│  └─ Halo Family (20 orbits)
└─ 📡 星历
   └─ orbit_ephemeris_...
```

交互方式：

- **单击**：选中工件并渲染到画布；
- **Ctrl+点击**：多选，画布叠加对比；
- **右键**：按工件类型弹出可用操作（见下）；
- **右键 → 删除**：删除输出文件（删除前要求确认路径）。

## 右键操作

右键菜单随选中工件类型变化：

| 工件类型 | 右键可用操作 |
|----------|--------------|
| 轨道（含星历数据） | 轨道保持、稳定性分析、删除 |
| 轨道（仅 CR3BP 数据） | 稳定性分析、删除 |
| 轨道族 | 删除 |
| 星历（轨道保持结果） | 删除 |

其中**轨道保持**与**稳定性分析**把选中工件作为输入，直接进入对应工具；
无需在右侧工具选择器中重新选择。

## 日志面板

中央标签页与画布并列。运行工具时逐条输出进度：

```
[14:32:01] 开始设计 DRO 轨道...
[14:32:15] 微分修正收敛 (3 次迭代, 残差 2.3e-12)
[14:32:18] 星历修正完成 (two_level, max_res=1.6e-02 km)
[14:32:20] ✓ 设计完成: DRO, C_J=3.005811
```

计算在后台线程执行，运行期间界面不阻塞；日志会说明失败原因，参数校验失败
（如轨道保持仿真时长超出标称星历覆盖）会直接拦截并提示。
