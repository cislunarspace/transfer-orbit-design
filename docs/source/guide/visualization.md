# 可视化

画布是右侧的 Three.js 3D 视图（会合系，质心归一化坐标），展示族生成结果与
轨道库叠加轨迹。

## 交互

- **左键拖拽**：旋转视角；**滚轮**：缩放；**右键拖拽**：平移。
- **适配**（画布工具栏）：按当前轨迹的包围盒重设相机，按包围盒对角线长度留 5% 余量。
- **视图保持**：首次数据到达时自动适配一次；此后增删轨迹不重置相机，
  手动旋转缩放的视角不被打扰（CONTEXT.md 领域语义）。
- **投影与中心**（画布工具栏）：投影在 3D 与 XY / XZ / YZ 三视图间切换；
  中心在地月质心、地心、月心与 L1 / L2 平动点间切换。

## 时间轴

画布下方的时间轴在有时刻数据时可用：拖动滑杆或点播放，画布上的时刻
标记沿轨迹插值移动，读数以自起点的偏移天数（T + N 天）表示。时刻来源：
周期轨道按周期均匀合成；星历类结果用响应自带的 epochs；无时刻信息的
点集时间轴保持禁用。

## 标注与配色

画布固定绘制地球、月球与 L1/L2 平动点球体及文字标注。多条轨迹按颜色循环
自动配色：族生成成员一组颜色，库叠加轨迹依次取后续颜色。

## 图表设置

画布工具栏的图表设置打开设置面板，即时生效并持久化（localStorage），可一键
恢复默认：

- 轨道线宽；
- 地球 / 月球 / 平动点标注大小、平动点颜色；
- Z 轴比例（近平面轨道防压扁）。

## 导出动画

画布工具栏的导出动画录制 8 秒画布自转（30 fps），经浏览器 MediaRecorder 编码
为 `orbit-animation.webm` 下载；不依赖外部编码器。录制期间按钮显示进度态，
结束后自动停止自转。

## 视觉语言

界面遵循严肃语义色板（ADR 0020）：全局 2px 直角；用色限定黑/白/灰/红/蓝/绿/橙七种色相——红=错误、绿=成功、橙=警告、蓝=主色/信息，中性色沿用 antd 灰阶，主色为收敛深蓝。画布内轨迹配色仍按颜色循环自动分配（见上文标注与配色）。
