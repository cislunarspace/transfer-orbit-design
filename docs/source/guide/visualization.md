# 可视化

画布是主窗口中央的内嵌 matplotlib 绘图区，展示轨道工件与轨道族。工具栏
分五组：**投影**、**坐标系**、**中心**、**绘制内容**、**图层开关**，另加
**导出动画**按钮。

## 投影

| 按钮 | 含义 |
|------|------|
| 3D | 三维视图，可拖拽旋转观察 |
| XY / XZ / YZ | 平面投影，取对应坐标面对 |
| 四视图 | 2×2 网格同时显示 3D + XY/XZ/YZ，适合大窗口或全屏 |

## 坐标系

| 按钮 | 含义 |
|------|------|
| 会合系 | CR3BP 旋转坐标系（无量纲），画地月天体与 L1–L5 平动点标注 |
| 惯性系 | GCRS/J2000 地心惯性系（km），地球为原点，月球沿真实轨迹移动，不画平动点 |

两套坐标系随**中心**按钮组合：会合系下中心可选质心 / 月球 / L1 / L2；
惯性系下中心为地球原点（月球按钮仍可平移视角）。

## 绘制内容

轨道设计产物同时携带 CR3BP 初猜与标称星历两份轨迹，三者选一：

| 按钮 | 含义 |
|------|------|
| 叠加 | 初猜（实线）+ 星历（虚线），TAB10 相邻色区分，默认 |
| 初猜 | 仅 CR3BP 周期初猜。惯性系下灰显（CR3BP 无量纲无惯性系表示） |
| 星历 | 仅标称星历 |

轨道保持产物只有受控星历，"初猜"恒灰显。

## 图层与等比

- **地月**：显示地球、月球位置（可随中心切换偏移）；
- **L1-L5**：显示五个平动点标注（仅会合系）；
- **等比**：勾选后各轴等比例（默认），取消后各轴独立缩放填满画布。

## 多轨道叠加

Ctrl+点击项目树选中多个工件，画布按 TAB10 调色板自动分配颜色叠加渲染；
轨道族按成员逐条渲染，成员数多时可用"等比"关掉等比例观察。每个视图自动生成
图例，标明轨道名称，以及叠加视图中的初猜和星历线型。

## 图表设置

菜单"设置 → 图表设置…"打开对话框，可调：

- 轨道线宽；
- 颜色方案（预设配色，含适合深色背景的方案）；
- 标注大小（地月天体、平动点标注字号）；
- Z 区间比例（3D 视图 Z 轴的视觉压缩/拉伸比例）。

设置保存到系统配置，重启后保留。

## 导出动画

工具栏"导出动画"把选中的星历工件按时间等分采样逐帧渲染，Pillow 合成
GIF（不依赖 ffmpeg）。支持：

- **累积 / 滑动窗口**两种帧模式；
- 帧率与总时长设置；
- UTC 帧时间戳标注；
- 坐标系随当前视图（会合系或惯性系均可）。

初猜模式无物理时间轴，导出动画按钮会拒绝导出。
