# 参数参考

GUI 工具中常见参数的说明。

## 绘图参数

### 投影平面

`--projection-plane`：选择 3D 轨道图的投影平面（xy/xz/yz）。默认 xy 平面（黄道面），适用于大多数地月轨道可视化。

### 绘图中心

`--plot-center`：选择绘图坐标系的原点。
- **月球**（默认）：以月球为中心，适用于 DRO/RO 等绕月轨道
- **地球**：以地球为中心，适用于 GEO/LEO 转移轨道
- **地月质心**：以地月系统质心为中心，适用于全局视图

### 仰角 / 方位角

`--elevation` / `--azimuth`：3D 视图的观察角度。
- 仰角：视线与 xy 平面的夹角（0°=平视，90°=俯视）
- 方位角：视线在 xy 平面内的旋转角度（0°=从 +x 方向看）

### 图片 DPI

`--dpi`：保存图片的分辨率（dots per inch）。默认 150。打印用途建议 300+。

### 子采样

`--max-points`：散点图的最大采样点数。数据量过大时降低此值可提高渲染速度。
`--seed`：子采样的随机种子。固定种子可保证结果可复现。

## 轨道生成参数

### 文件类别

`file_category`：文件选择器的过滤类别。
- `dro`：DRO 轨道 JSON 文件
- `halo`：Halo 轨道 JSON 文件
- `ro`：RO 轨道 JSON 文件
- `transfer`：转移搜索/优化结果 JSON 文件

### 路径模式

`--path-mode`：文件路径的输入模式。
- **绝对路径**：直接输入完整路径
- **相对路径**：相对于项目根目录的路径

## 任务管理参数

### 并发上限

`MAX_CONCURRENT`：同时运行的最大任务数，默认 8。超过此上限时"运行"按钮显示为"已达上限"。

### 包含完整轨迹

`--include-full-trajectory`：星历修正输出是否包含完整的 J2000 轨迹数据。启用后输出文件会显著增大。

### 首次失败即停止

`--fail-fast`：轨道族转换遇到失败时立即停止，而非跳过失败项继续处理。适用于调试场景。

## 转移设计参数

### 可行解

`--top-k`：从网格搜索结果中选取前 K 个可行解进行 NLP 优化。留空表示优化所有可行解。

### NLP 参数

`--nlp-maxiter`：NLP（非线性规划）求解器的最大迭代次数。
`--nlp-ftol`：NLP 求解器的函数容差。更小的值意味着更精确但更慢。

## 星历转换参数

### 修正方法

`--method`：星历修正方法。
- `standard`：标准修正
- `two_level`：两阶段修正（默认，推荐）
- `homotopy`：同伦过渡（适用于困难收敛场景）

### 位置容差

`--position-tol`：轨道拼接点的位置连续性容差（km）。默认 1e-3 km。
