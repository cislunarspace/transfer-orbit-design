# GUI 使用指南

## 界面布局

```
┌─────────────────┬────────────────────────────────────┐
│                 │  [Script Info]  [Files]  ← 右侧标签 │
│  DRO            │                                     │
│  RO             │  参数控件（单位选择器）                   │
│  Halo           │  文件下拉（env_params）                 │
│  Transfer       │  ──────────────────────               │
│  Ephemeris      │  [运行]  ← 固定在面板底部               │
│  Inspection     ├────────────────────────────────────┤
│  ← 左侧标签页     │  输出面板（每个 Job 一个标签）           │
└─────────────────┴────────────────────────────────────┘
```

左侧标签按任务分组（生成/绘图/转移/星历/检查），右侧显示选中脚本的参数和输出。

## 标签页说明

| 标签 | 内容 |
|------|------|
| DRO | DRO 轨道生成与绘图 |
| RO | RO 轨道（3:1、3:2、RRO、ARO）生成与绘图 |
| Halo | Halo 轨道生成与绘图 |
| Transfer | 4 种转移类型的网格搜索和优化脚本 |
| Ephemeris | CR3BP → 星历修正（多重打靶 / 同伦） |
| Inspection | 单轨道可视化与交互式检查器 |

## 参数控件

脚本参数分两类：

### CLI 参数（cli_params）
- 由 `ScriptEntry.cli_params` 定义
- 支持类型：float、int、str、bool
- 提供单位选择器（distance / velocity / time / angle）

### 环境参数（env_params）
- 由 `ScriptEntry.env_params` 定义
- 渲染为文件下拉框，从 `output/` 目录自动发现 JSON 文件
- 通过环境变量传递给子进程

## 运行脚本

1. 在左侧选择脚本类型（标签页）
2. 在脚本列表中点击目标脚本
3. 调整参数（可选）
4. 点击「运行」
5. 在底部输出面板查看结果

## 输出面板

每个运行的 Job 有一个独立标签，显示：
- stdout / stderr（带 ANSI 颜色）
- 时间戳
- Job 卡片（ID、状态）

## 设置

设置对话框可调整：
- 主题（dark / light）
- 每行最大字符数
- 字体

## 环境变量

部分脚本需要环境变量（如 SPICE_KERNEL_DIR）。在「Script Info」标签页顶部设置，环境变量传给所有子进程。
