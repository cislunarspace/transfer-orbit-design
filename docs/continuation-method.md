# 参数延拓方法

## 目的

延拓通过从一个初始解逐步改变参数来生成周期轨道族。这探索了轨道特性如何随系统参数变化。

## 自然延拓

最简单的方法：在每一步重新应用微分修正的同时改变一个参数。

### 算法

```
1. 从参数 p₀ 处的种子轨道开始
2. 对于每一步 i：
   a. 设置 p_{i+1} = p_i + Δp（步长）
   b. 使用前一个轨道作为初始猜测
   c. 在新的 p_{i+1} 处应用微分修正
   d. 如果收敛，添加到轨道族；如果失败，减小步长或停止
3. 继续直到达到参数限制
```

### 参数选择

对于 DRO 族：改变初始 x 位置 $x_0$

对于 RO 族：在 y 幅值点改变 $x_0$

### 步长选择

| 因素 | 考虑 |
|------|------|
| 稳定性 | 快速变化时用更小步长 |
| 效率 | 行为平滑时用更大步长 |
| 鲁棒性 | 自适应步长可能有帮助 |

典型值：0.001 到 0.01

### 轨道族生成脚本

```python
from e2m2e.algorithms import Continuation

continuation = Continuation(corrector=corrector)
family = continuation.natural_continuation(
    seed_orbit=seed_dro,
    param_range=(0.6, 0.8),  # x0 范围
    step_size=0.005
)
```

## 伪弧长延拓

对于穿过奇异点（自然延拓失败的地方）：

### 算法

```
1. 用弧长约束 s(s) = 0 增强系统
2. 沿切线方向进行预测步
3. 同时校正参数和约束
```

这允许穿过 da/dp = 0 的折叠点。

## 轨道族特性

当 $x_0$ 在 DRO 族中变化时：
- Jacobi 常数 $C_J$ 变化
- 周期变化
- 稳定性可能变化（特征值穿过单位圆）

### 稳定性指数

从单值矩阵特征值：

$$|\lambda_i| \begin{cases} < 1 & \text{稳定} \\ = 1 & \text{中心} \\ > 1 & \text{不稳定} \end{cases}$$

最大特征值幅度定义稳定性指数。
