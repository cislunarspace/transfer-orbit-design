# Triage 标签

技能用五个规范的 triage 角色来表述。本文件把这些角色映射到本仓库 issue 跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们的跟踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 issue |
| `needs-info`               | `needs-info`         | 等待提交者补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已充分定义，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现 |
| `wontfix`                  | `wontfix`            | 不会处理 |

当技能提到某个角色（例如“打上 AFK-ready 的 triage 标签”）时，使用本表中对应的标签字符串。

把右列改成你实际使用的词汇即可。
